baoanlight
Free & open source

A desk robot for your AI coding agents.

Stop alt-tabbing to find out whether it's still thinking or has been waiting on you for five minutes. Glance at the corner of the screen instead — the robot digs while it works, waves when it needs you, and powers down when nothing is running.

Claude Code thinking
Green — it is working. Bright means running, right now.
Yellow — it stopped and needs you. A permission prompt, a question, a choice.
Red — this run failed, or it is blocked and will not recover alone.
Purple — it just finished. Deliberately not green: green means it is still working.
Dim — the software is open but idle. Green is never used to mean "not working".

Install

# macOS, Windows, Linux
npm install -g baoanlight
bao setup

# run it, then wire in your agent
bao start
bao connect claude

Works with any agent

Claude Codeall three states Eight lifecycle hooks — bao connect claude
Codexall three states Reads its own session log — bao watch codex, and drives the charge gauge from its real quota
DeepSeek Harnessall three states Its per-session projection — bao watch deepseek, or bao hook --agent deepseek
WorkBuddyall three states Its task board — bao watch workbuddy; exact via bao hook --agent workbuddy
Gemini, Aider, Cursor, opencodeall three states A watched pseudo-terminal — bao wrap -- gemini
Anything elsewhatever you report One line of shell — bao set waiting --agent deploy

Drag it anywhere; clicks pass straight through to whatever is underneath. Run several agents at once and each gets a label, while the robot shows whichever most wants your attention. The slim gauge beside it tracks how much plan quota or context you have left.

Nothing leaves your machine — the whole thing is a local server on loopback holding the current state of each session, and nothing else.
